# 整体研究判断

## 最有价值且证据较充分的发现

最有研究价值的发现是：**在当前职业任务中，U职业回答进步、G人口比例变化和公平迁移可明显分离，且这种分离依赖监督方向与生成场景。** 匹配六次训练、三个seed、全部预定检查点后，G监督的肖像RD下降而工作RD上升；U监督的职业选择提升不等于稳定的人口公平源收益。旧训练轮数不再能单独解释全部差异。[RQ4](research_questions/RQ4_sft_transfer.md)

第二个直接成立的发现是测量混杂：固定图像仅换U读者，差距下降但较弱组没改善；原解析器的格式拒绝也制造了部分表面收益。这些是对当前结果的可隔离诊断，支持评价协议贡献，但还没有独立人工真值以量化自动评审真实偏差。[RQ1](research_questions/RQ1_measurement.md)

第三，开放描述模板化与部分字段仍可读、题式/位置强影响并存。它反驳“不说即不会”和“人口词减少即公平”的简单推断。概率复核及完成的48张真实图面板显示分数排序与采样行为可以脱钩，严格格式与辅助语义计数甚至会给出相反的变化方向；其小样本及机器参考使它仍是诊断发现，不能升级为完整内部知识保留理论。[RQ5](research_questions/RQ5_behavior_and_probability.md)

## 有趣但仍不可靠的结果

- 最好U seed98.44%与其他seed差异大，且收益集中于原选项位置弱项；不能称完全学会视觉职业语义。
- 单次旧SFT组差7.39→2.27pp有固定模型区间支持，但新匹配三seed没有确立同类稳定公平收益。协议与样本不同，不能挑一个替代另一个。
- G-source的2/16女性变化依赖职业/seed；text-U无可靠增量，缺竞争力强的普通G对照。
- 层组撤销有功能作用，但只有一个seed、一组随机层、幅度不同；不能给某层贴“公平/偏差来源”标签。
- codec整体失真未见确定组差，不代表脸/工具细节完全无差异；历史Janus部分证据已删除，更不能据存留图表增强结论。

## 为什么有这么多版本

必要修改包括：构图和职业真值资格、真实loader DEBUG筛选、官方参考配置、解析器敏感性、动态U token路由发现，以及预算/文本/顺序匹配。它们解决了具体问题，不能简单归为重复试错。

低收益重复主要是：源公平尚未确立就继续扩展G网格；反复使用同一小开发图；用不同读出/格式修复追逐更好分数；从属性可控或像素变化直接跳到公平机制。当前应把这些尝试整合为测量与方法边界，而不是再命名一个成功方法。

## 应暂停/停止投入的路线

| 路线 | 当前决策 | 证据理由/重新进入条件 |
|---|---|---|
| 低CFG直接去偏 | 停止按现设置扩展 | 合格和明确遵从明显减少，J无可靠联合收益 |
| 将7–13层当普适公平通路 | 停止作为已验证方法 | 独立职业/seed源收益不稳定；原定位受G开发信息影响 |
| 当前CelebA CDRO/校准隔离继续刷G矩阵 | 暂停 | 相对ordinary无稳定源公平增量，目标近天花板或评审不确定 |
| 同一中立职业模板继续加轮数 | 停止以“多训即可公平”为理由延长 | 三seed后期并非更好，模板化从首保存点已出现 |
| Janus条件先验CE路线 | 暂停同目标重跑 | 所有U臂未过预定先验门槛，损失下降主要含标签支持质量变化 |
| 更多缺人审的角色生成/读出版本 | 暂停 | 同图评分反转，空白标注包尚未完成 |
| 大规模SAE/交互跨度机制搜索 | 暂停扩展 | 公平源端未建立，候选可读/可达尚不是不当关联因果证据 |

这是对当前设置和投入次序的判断，不是否定这些方法类别的普遍价值；失败证据完整保留。

## 最值得继续的方向与优先级

1. 先独立核验已完成真实256视图面板的参考与类别覆盖。实际结果重现题式风险，并显示严格一致与辅助语义的变化方向相反；优先审查该解释，不再重复已有推理。
2. 完成已有角色/工作图的实际人工参考，固定职业/动作/呈现及未知判据；用全计划分母联合评价，验证肖像均衡是否来自取景和场景表达变化。
3. 若继续训练，只做能区分解释的监督对照：固定事实包，操纵信息范围与任务多样性（已设计2×2但未执行）。先验证一个人口编辑不变且事实变化响应的源公平终点，再测试G；控制普通监督和曝光，避免把一般任务学习写成公平特有效果。
4. 源收益成立后才做冻结算子的恢复/移植与真实G条件通路验证，并区分参数增量幅度、位置和动态路径。

## 距离完整论文还有多远

当前不适合写成“提出通用高效双端去偏方法”或“发现UMM偏差主要起源于共享LM”的强方法论文。成功源公平、稳定跨端额外收益、质量保持、内部因果链和独立人工确认都不完整；不能用36,960张生成数量替代这些缺口。

最有希望的论文问题是：**为什么职业理解与生成的人口公平读数不一致，如何用可识别的监督/测量对照区分真正迁移与输出策略、场景及评审变化？** 已有统一故事可由四部分构成：测量交叉重放 → 作者代码复现与源收益核查 → 同图文/曝光匹配的方向×场景结果 → 有限参数撤销的两端贡献分离。所有负面结果必须保留，且把“现象及验证协议”与“尚待成功的方法”分开。

形成强实证论文的关键缺口是：实际人工职业/动作/属性参考与评审误差；独立确认样本而非循环开发；监督事实/形式对照以检验模板解释；至少在一个清晰端点上确立可重复源公平收益，随后检验其对端联合影响。若继续主张跨架构或通用机制，现有BAGEL/SenseNova/VILA-U/历史Janus异协议结果远不足以支持，需另冻结共同可比设计。

现有研究已回答多项“哪些简单解释不成立”，也建立了部分可达性和可靠负结果；尚未回答“一种有效公平能力如何稳定迁移”的核心方法问题。这应成为下一阶段唯一优先进入条件。
