# 结果图约定

在正式评分之前确定图的内容，数据未完成时不绘制结果。使用 Python / matplotlib，中文标签，SVG 保留文字、PDF 嵌入字体，并导出 300 dpi PNG 和来源 CSV。主要图宽 183 mm，按内容调整高度；不使用立体图或截断比例坐标。

## 图一：降低引导后，各职业的合格人物分布怎样改变

图要支持的判断：比较分布时，必须同时看合格图片数和两名评审的不同读数，不能只看一个总体男女比例。

两模型×两评审构成四个面板。每职业画 CFG4、CFG1 两条横向堆叠条，每条总长为全部计划的 8 张；分别显示合格 masculine、合格 feminine、其余计划样本。其余样本包括工作内容不匹配、非单人、未知、不可读或缺失，详细原因在表格中展开，不能称其均为生成失败。直接标明计数，不画不必要的误差线。

## 图二：分布、条件遵从和质量的变化是否一致

以六职业等权的 J、明确 male/female 条件的联合通过比例，以及严重缺陷比例呈现基线与弱引导。两模型和两评审分别报告。比例范围固定为 0–100%，J 的具体公式与分母在图注给出，不能称为人口公平概率。若用探索性重采样区间，须注明固定提示集合和组内配对，不能把机器评审误差包含在区间内。

## 重构表与固定示例

BAGEL 原图与重构的逐项读数变化、缺失造成的边界、源呈现分层用表表达。像素误差只记录处理产生的图像差异，不当作公平证据。

附图如制作，固定选每职业模板0、重复0的中性图，列出全部六职业和两种 CFG。模型分开排列；不因内容好坏替换。只等比排版，不裁剪、不增强、不修图。原始 PNG 与每张图对应 ID 可追溯。示例不代替全部计划样本的统计。

## 复核风险

- 每职业每 CFG 只有 8 张中性图，计数变化粗；不通过图形暗示精确估计。
- 两评审不是两份独立生成重复，更不是金标准。
- 原图和重构图、同噪声不同条件存在依赖，不能叠加当作独立 N。
- CFG 的作用按模型内比较；不根据跨模型差异推断相同部件的因果作用。
