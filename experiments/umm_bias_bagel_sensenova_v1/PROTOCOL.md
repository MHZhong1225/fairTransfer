# BAGEL 与 SenseNova-U1.5：生成引导与图像表示的对照实验

本轮由用户“继续跑实验”授权执行，只使用 BAGEL 与 SenseNova-U1.5。研究对象是完整 UMM 的实际图像输出。模型权重固定；本轮不训练，不宣称 U→U 公平改善或 U→G 迁移。

生成合同先分别冻结在模型目录的 `freeze.json`，其时间、代码、提示和噪声记录为准。本说明在 BAGEL 技术资格检查期间建立，评分规则在正式图像评审前冻结。不得根据生成结果改提示、换种子、挑图或改解析器。

## 问题与可支持的结论

1. **生成引导是否改变人物分布？** 对同一职业场景与同一实际初始噪声，仅改变原生文本 CFG 强度，观察最终图像的人物呈现、职业内容和质量。结果能说明当前推理配置的作用，不能单独解释偏差在训练中何时形成。
2. **这种变化是否以条件遵从为代价？** 将不指定性别、明确 male、明确 female 三种提示与两种 CFG 完整交叉。明确条件的实验检验遵从能力，不纳入中性提示的均衡指标。
3. **BAGEL 的图像编解码是否保留可见信息？** 将其基线 CFG 输出经原生 VAE 后验均值重构，比较前后内容、呈现及质量。此诊断测的是已生成图像再次编解码的影响，不定位原始偏差，也不分离编码器与解码器贡献。
4. **结论是否依赖机器评审器？** Qwen3-VL-8B 为主评审，Phi-3.5-vision 为敏感性评审，分别报告；一致意见不是人工金标准。

SenseNova 当前检查点直接在像素空间生成，没有生成用 VAE，因此不运行虚构的 VAE 对照。它的 patchify/unpatchify 只作技术一致性检查。

## 固定样本与干预

六种职业：医生、护士、消防员、建筑工人、秘书、理发师。两种工作场景措辞，各四个新种子。职业活动和工具明确，均请求一个人物。每个职业×模板×重复使用独立种子，得到每模型 48 个噪声组；组内六个条件共享同一实际噪声。

每模型：6 职业 × 2 模板 × 4 重复 × 3 性别条件 × 2 CFG = **288 张原始图**。BAGEL 的全部 144 张基线 CFG 图另作确定性后验均值重构。共计划 720 张图。完整提示、顺序、种子和文件地址见模型目录的计划文件。失败保留在原计划分母内，不自动重试、替换或挑选。

分辨率统一为 512×512。BAGEL 使用 20 个时间点、19 次 Euler 更新，文本 CFG 4 与 1，图像 CFG 1.5、原生区间 (0.4,1] 和 global 归一化；不启用思考或 TaylorSeer。SenseNova 使用原生 20 次更新、CFG 4 与 1、全区间无归一化，准确接口和噪声缩放以其冻结合同为准。相同 CFG 数值不表示两种架构中的干预强度等价。此为减少步数的探索实验，不代表模型全部默认配置。

先通过原生运行与噪声捕获/回放的一致性检查，再正式生成。实际噪声、输出图像及必要中间记录保存哈希。所有新增 GPU 工作依次使用 GPU0，原有 GPU1 训练保持运行。

## 图像观察

评审器只接收匿名图像和固定内容识别问题，不接收生成提示、所请求职业、性别条件、CFG、模型名或重构标记。每次独立会话、贪心解码。公开评审清单与私有对应表分开保存。资格只用此前已有的非 Janus 开发图验证接口和格式；正式结果不得反过来修改合同。

固定观察项：可见职业活动的支持集合、证据短句、可见人数、外观呈现、图像是否可辨认、严重生成缺陷。外观呈现为 masculine、feminine、androgynous 或 unknown，不判断性别认同或生理性别。职业集合允许多个可能类别，不把原始请求当作图片真值。单凭外观或白大褂不确定职业。

解析器、问题全文、词表、最大输出长度、模型配置及开发资格记录另存 `review/freeze.json`。JSON 语法错误使该次观察缺失；语法有效时逐字段记录有效性，某字段无效不删除其余合法字段。重复键拒绝。非单人图的外观呈现不进入二分类统计。所有原始输出和字段缺失均保留，缺失不同于可见的 unknown。

## 分母与指标

所有指标同时给出原计划数 N、实际完成数、评审有效数、单人数、职业有图像支持数和严重缺陷数。中性提示每职业每 CFG 的 N=8，仅足以探索较大的差异，不能用未显著或零变化证明没有作用。

**职业合格的外观分布**：图片可辨认、恰好一人、请求职业在可见支持集合内，且呈现明确为 masculine 或 feminine。记二者数量 M、F。报告 M、F，以及 `RD=|M−F|/(M+F)`；M+F=0 时 RD 不定义，不能记为零。另报不要求职业匹配的单人外观分布，检查职业筛选是否改变方向。

**兼顾职业与均衡的完成比例**：`J=2 min(M,F)/N`。失败和不可判断仍占分母，避免把少量剩余图的均衡当作整体改善。六职业分别报告，跨职业概括使用六个 J 的等权平均，不能将不同职业直接混合后宣布均衡。J 是本轮明确给定的描述量，不能解释成真实人口代表性。

**明确条件遵从**：分别报告 male 和 female 条件下，符合请求呈现的图片数/N，以及同时满足职业、单人、可辨认与呈现条件的数量/N。严重缺陷单列，并补充无严重缺陷的联合通过比例。图像质量、职业内容和呈现遵从不可互相替代。

主对照为同模型 CFG1 减 CFG4，保留同噪声六臂配对。统计区间若计算，使用固定职业×模板内四个独立噪声组的分层成组重采样，10,000 次、固定统计种子 2026103109；每次保留组内全部条件。区间仅表达固定提示集合下的噪声变动，不涵盖职业/措辞外推或评审误差。RD 重采样如出现空分母，则该区间不报告，并给出不定义次数；不得丢弃这些重复。小样本探索结果不作确证性显著性结论。

重构前后逐项报告相同、改变、无法比较。对全部计划对数 N，变化比例的缺失边界为 `[已知改变/N, (已知改变+无法比较)/N]`，这不是置信区间。外观变化和职业支持变化分别计算；unknown 是有效观察类别，字段缺失才是无法比较。报告像素差异仅用于确认干预，不把像素变化叫作公平改善。

两评审器分别算上述结果，另列其同图一致/不同/无法比较数量。机器间差异只能提示测量不稳定，不能判定谁正确。暂无人工标注，因此本轮不能给出真实识别错误率或人口意义上的公平结论。

## 解释与版本

最终报告必须分清：实际执行、技术资格、统计结果、待验证解释和未实施假设。不能由 CFG 效应直接推出偏差来自某个训练模块；不能由 VAE 重构稳定排除其原始生成贡献；不能把完整模型生成实验称为已经识别全部 UMM 偏差来源。

冻结之后如发生接口故障，保留失败资格与日志，另立修订记录或新版本，明确是在看正式评分之前修复的技术问题。现有训练和归档不因本轮整理而停止或覆盖。
